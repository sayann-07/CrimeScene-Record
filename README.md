# CrimeScene Record - Digital Evidence Documentation System

A professional, high-fidelity forensic evidence management system designed for digital documentation and archival.

## 🚀 Quick Start
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and select **"Open with Live Server"**.
4. Access the application in your browser.

## 🛠️ Features
- **Secure Entry:** Professional login gateway with session persistence.
- **Operational Dashboard:** Real-time metrics for total cases and evidence records.
- **Evidence Intake:** Structured documentation form with unique ID generation and validation.
- **Digital Archive:** Comprehensive evidence register with advanced search, filtering, and sorting.
- **Case Management:** Full CRUD (Create, Read, Update, Delete) capabilities for evidence records.
- **Professional UI:** Swiss-inspired design using a premium forensic color palette and typographic hierarchy.

## 📋 Project Overview (College Submission)
**Project Name:** CrimeScene Record  
**Course:** Third-Year Computer Science / Forensic Informatics  
**Objective:** To develop a lightweight, client-side digital evidence documentation system that simulates the rigor and structure of a professional forensic laboratory.

**Screen Breakdown:**
1. **Login:** Entry point with brand identity and credential validation.
2. **Dashboard:** High-level operational overview and recent activity.
3. **Add Evidence:** Formalized data entry for new forensic finds.
4. **Evidence Records:** The primary archive for searching and managing all documented evidence.

## ⚠️ Limitations
- **Frontend Only:** This is a demonstration system; data is stored in `LocalStorage`.
- **Security:** Authentication is simulated for educational purposes and is not production-grade.
